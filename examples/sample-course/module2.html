Advanced Topics in Common Cartridge

Metadata Standards

Common Cartridge uses specific metadata standards to describe educational content.

Resource Types

Different types of resources can be included:

  • Web content (HTML, CSS, JavaScript)
  • Assessments (QTI format)
  • Discussion topics
  • Learning activities

Best Practices

Follow these guidelines when creating Common Cartridge packages:

  1. Use valid XML in the manifest
  2. Include all referenced resources
  3. Test compatibility with target LMS
